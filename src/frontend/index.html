What cycles are

Cycles are prepaid credits that pay for your app's computation and storage. Buy them here, spend them as you build. No exchange account, no separate token to manage.

Nothing to run but your code

No servers to provision or patch, no database to host, no CDN or load balancer. Your code runs replicated across independent data centres and you pay for what it uses. How it works ↗

Build with an agent

Point your coding agent at the MCP server ↗ and the skills library ↗.

Checkable by anyone

Pricing and delivery run in a single audited program, and you can check the code. Every order carries a receipt that recomputes its own price from two canisters you can query yourself.
